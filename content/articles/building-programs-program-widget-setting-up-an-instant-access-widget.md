Designed for ecommerce and retail clients, instant access widgets provide your participants and their referred friends with an easy way to engage with your referral program—no password or authentication required. 

Instant access widgets can be set up for new referral programs, or for existing referral programs that use [fuel tank rewards](/features/rewards-fuel-tank). 

> We recommend setting up new widgets in your test tenant before using them for your live program. See our doc on [widget types](/topics/widget-types) for details about the instant access widgets’ features.

## 1. Set up the widget

1. Sign in to the SaaSquatch Admin Portal. 
2. Use the tenant selection dropdown to pick your live or test tenant.
3. Create a new program or edit an existing program that already uses fuel tank rewards.
4. On the *Program Setup* page, click __Customize__ beside either the website referrer widget or the friend widget to open the visual editor. 
    - __Tip:__ If you’re setting up the Friend widget, then select the toggle for *Show automatically to friends*. This is optional but recommended, as it enables the auto popup feature. Auto popup creates a more engaging referred friend experience by making the Friend widget stand out on the landing page. 
5. Adjust the appearance and contents of the template.
    - __Note:__ Components from the following groups can’t be added to instant access widgets: *Rewards, Statistics, Microsite Components,* or *Referrals*. For more information about how to use the visual editor, see [Customizing Program Widgets](/designer/widget-editor&sa=D&source=docs&ust=1684183524286681&usg=AOvVaw1Mu9k5eW5TPYtSSpKn8CBH).
6. Save your changes to the widget.

Repeat steps 3 to 5 if you want to set up the other instant access widget.

## 2. Create a fuel tank reward (optional)

If you’re using a friend widget, then we recommend setting up [fuel tank rewards](/features/rewards-fuel-tank). The fuel tank is a simplified way of handing out rewards using unique coupon codes. Your program participants can redeem these codes for rewards, including discounts, credits and other reward types. Clients supply the coupon codes for the fuel tank. You can either create these codes on your own, or use your existing ecommerce or billing platform to create them for you. 

__Note:__ If you already have fuel tank rewards set up for your program, then edit the reward and skip to step 7 to allow it to be used in an instant access widget. 

1. In the Admin Portal, go to __Rewards > Catalog__.
2. Select __Create Reward__.
3. Name the reward.
4. Select the __Fuel Tank__ reward type.
5. Use the __fueltank type__ dropdown list to choose a discount or credit reward.
6. Set a discount percent, or credit amount and reward unit.
7. Select __instant access__.
8. Save the reward.

## 3. Adjust your program rules (optional)

To start using fuel tank rewards in your program, you’ll need to incorporate them into your program rules. Skip this step if you aren’t using the friend widget to issue coupon codes. 

1. In the Admin Portal, go to __Programs__ and edit your program.
2. On the *Program Setup* page, set your program rules as usual.
3. Select __Set Reward__ beside the reward name under Section 1.
4. Select __Pre-configured reward__.
5. Use the *Reward* dropdown list to pick the fuel tank reward you created. 
6. Save the reward selection.

## 4. Embed the widget
Congrats! Your instant access widgets are ready to use. The final step is to generate a code snippet to embed into your post-purchase landing page, checkout flow, or wherever you want participants to access them. 

1. In the Admin Portal, go to __Settings > Install__.
2. Go to the *Display widgets* section.
3. Follow the on-screen instructions to generate the code snippet you need to embed. 
4. Add the code snippet to your ecommerce platform or landing page.
