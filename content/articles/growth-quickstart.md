The SaaSquatch Growth Automation Platform is designed to help you quickly, and easily, launch new referral and loyalty Growth Automation programs from right within the SaaSquatch portal.

The following **Quickstart Guide** provides end-to-end overview of this setup process.
### Select a Program
<div class="row-fluid">
  <div class="span8">

  <p>From the <i>Programs</i> section inside the SaaSquatch portal, select the <i>Create New</i> program option from the top left of the page. 

  <p>Here you are presented with a Program Library filled with different types of programs your SaaSquatch project supports. Each entry includes details on the functionality the program is designed to provide, and the data required to run the program.

<p>Once you have settled on a type of program you would like to create, click the <i>Create this Program</i> option to be taken to the Program Creation Wizard which will walk you through the setup process.

### Rules
<div class="row-fluid">
  <div class="span8">

  <p>The rules you configure for a SaaSquatch program will be evaluated each time the program is triggered for a specific user. These <a href="/growth/ga-mechanisms/#program-rules">triggers</a> are typically based on updates to user information, new user events, or time-based thresholds.

<p>Each SaaSquatch program is structured differently, and therefore will have different rules for when rewards should be created and when emails should be sent. Further details about the specific rules & requirements for each program can be found on the <a href="/program/library/">respective program&#39;s summary page</a>.

<p>Once the criteria outlined in the program rules have been successfully met, the program will take action. This might include providing the user with a reward and/or sending them an email.

  <p><a href="/growth/ga-mechanisms">Learn more</a> about the role that program rules play in a Growth Automation program.

### Rewards
<div class="row-fluid">
  <div class="span8">

  <p>Many SaaSquatch Growth Automation programs provide the ability to reward users that have successfully reached your program's configured threshold (set out in the rules section).

<p>The SaaSquatch platform supports a wide range of reward types, and enables you to independnatly configure the reward(s) for each program you configure. This enables you to provide the right customer the right reward at the right time in their customer journey. 

<p>Learn more about the types of rewards supported on our <a href="/feature/rewards">Growth Automation platform</a> and in each of our available <a href="/program/library">Growth Automation programs</a>.

### Widgets

<div class="row-fluid">
  <div class="span8">

  <p>A number of Growth Automation programs have been built with an option for engaging program participants through the use of a widget. This widget can be configured from the Widgets page in the program setup wizard or from the Content tab.
  <p> SaaSquatch offers two types of widgets--verified access and instant access. See our doc on <a href="/topics/widget-types/">widget types</a> for more information.

<p>This WYSIWYG editor provides the ability to customize the layout, messaging, and design of the widget from within the SaaSquatch portal. 

<p>This widget can then be displayed to program participants using our <a href="/developer/squatchjs/v2/">JavaScript library</a>.

### Emails

<div class="row-fluid">
  <div class="span8">

  <p>The SaaSquatch system can be configured to send program participants emails as part of their activity within the program. 

  <p> These emails can be useful for communicating with a user about their progress through the program, or about a reward they might have earned for successful participation in the program. 

  <p> The content, design, and layout of these emails can be customized directly in the SaaSquatch portal.

### Settings 
Some growth Automation programs include addtitional program functionality and configurability that can be controlled from within the SaaSquatch portal. 

For these programs (including referral, affiliate, and partner programs) these settings include configuration options for the following program components:

- Referred User [landing page](/success/intro/#landing-page) and falback URL settings
- Referrer [default share messaging](/success/share-options/#social-media-share-messages) and [Open Graph Metadata](/success/share-options/#open-graph-metadata)

### Publish
<div class="row-fluid">
  <div class="span8">

  <p>Once you have finished configuring your program, return to the <i>Programs</i> page in the SaaSquatch portal. From there, select the <i>Launch Program</i> option from behind that program's "gear" icon.

<p>This will publish your program and allow your users to interact with it.

 <blockquote><strong>Note:</strong> If you encounter errors while launching the program, recheck that you have completed all the required fields within the program configuration.
<br><br><i>Review</i>: Rules, Rewards & Setting pages (a landing page URL and a hosted image link for Open Graph, LinkedIn and Pinterest are mandatory)</blockquote>

### Analytics
<div class="row-fluid">
  <div class="span12">

  <p>As users begin interacting with your Growth Automation program, this activity will be tracked by the SaaSquatch system.

<p>Each type of Growth Automation program will be configured to track a different set of metrics that are relevant to the program's specific goals and user journey. 

<p>These aggregate analytics are then viewable either from the analytics page within the program configuration, or by filtering the overall analytics from the <i>Analytics</i> page in the Reporting section of the portal.

  </div>

</div>
