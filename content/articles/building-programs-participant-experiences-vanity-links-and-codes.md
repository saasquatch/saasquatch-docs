## Overview
SaaSquatch automatically generates unique share links and referral codes for each of your participants to use when they refer friends in your different programs. We also offer the ability to personalize a participant’s sharing experience by creating vanity share links or vanity referral codes. 

Vanity links and codes are assigned on a participant-by-participant basis, and must be unique to that participant. Additionally, like all share links and referral codes, they can only be associated with one specific program (if you have more than one running). Each participant can have multiple vanity links and codes active at the same time. 

We typically recommend vanity share information when you want to provide a personalized, memorable link or code for a well-known or top-performing referrer, such as an affiliate or partner. One example would be a social media influencer who shares their referral code for your program in their posts or captions, especially as part of a targeted campaign (such as 10% off their first purchase as a new user).

## Open the participant's profile
All vanity share links and codes are managed on individual participants' profiles. To view this information on a participant’s profile:

1. Sign in to the Admin Portal.
2. Go to the __Participants__ page and select the participant whose code you want to change. This opens their participant profile.
3. Select the __Codes and Links__ tab below the participant’s program info. 

## Assign vanity referral codes
You can convert an existing referral code to a vanity code, or create a new vanity code. 

### Change an existing referral code
1. Under the *Referral Codes* heading, select the three-dot menu beside the referral code you want to change. 
2. Enter the new referral code in the text box.
3. (Optional) Deselect *Keep `CODE` as a working referral code* if you want to permanently disable the old referral code.
    - __Tip__: We recommend disabling the old referral code if you suspect potential referral fraud or if it was, for example, used as part of a now inactive campaign.
4. (Optional) Deselect *Keep using existing sharelinks* if you want to have a new share link automatically generated.
5. Save your changes. 

### Add a new vanity referral code
1. Under the *Referral Codes* heading, select __Add Referral Code__.
2. Select the program you want the referral code to be used for.
3. Enter a vanity referral code in the text box.
4. Set the referral code as a primary or secondary referral code for this program.
    - __Tip__: Secondary referral codes don’t show up in the program widget, emails or other participant touchpoints. Secondary codes can be useful when you want to run targeted campaigns or other limited-time promotions. 
5. Save your changes.

A new unique share link is automatically generated if you select *Set as primary referral code*.  If you want this new share link to match the vanity referral code, then see the section on changing an existing share link.

## Assign vanity share links
> __Before you begin:__ To use vanity share links, you must have [set up a custom domain](/building-programs/participant-experiences/configuring-a-custom-domain) on your tenant. 

### Change an existing share link
Any existing share links can be modified with vanity information. If you previously created a new vanity referral code, then you can follow this process to customize the share link that was automatically generated. 

1. Under the *Sharelinks* heading, select the three-dot menu beside the share link you want to change.
2. Select __Edit__ and update the text at the end of the URL with the new vanity code.
3. (Optional) Deselect *Keep `LINK` as a working share link* if you want to permanently disable the old link.
    - __Tip__: In the event of potential referral fraud or when retiring links from now inactive campaigns, you can return later and disable old links from this menu. 
4. Save your changes.

### Add a new vanity share link
__Note:__ New vanity share links can be added even when you aren’t creating a corresponding vanity referral code. This option is especially useful for targeted or limited-run campaigns.

1. Under the *Sharelinks* heading, select __Add Sharelink__. 
    - __Note:__ This button is only displayed after you’ve set up a custom domain. 
2. Select the program you want the share link to be used for.
3. Enter a vanity code in the text box at the end of the URL. If you previously created a new vanity referral code, then you can re-use this code for the share link. 
4. Set the share link as a primary or secondary link for the program.
    - __Tip:__ Primary links are used in widgets, emails, API and integrations. Secondary links are not.  Secondary share links can be useful when you want to run targeted campaigns or other limited-time promotions. 
5. Save your changes.
